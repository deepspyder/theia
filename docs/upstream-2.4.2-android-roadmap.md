## 排期与逐项验收

优先交付稳定性和独立功能，再接多源与局部处理；HDR/外部生态最后按能力开放。不预估未经测量的发布日期。每项按“合同/迁移 → 底层 → 持久化/缓存 → 页面 → 单张/批量/灯台输出 → 回归/性能 → 更新进度”闭环。
