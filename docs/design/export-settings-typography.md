## R08 行为与 UI 合同

日期：2026-11-19。普通延伸 incumbent Theia 暗房导出页；保留既有 DESIGN.md token、圆体、琥珀选中态、滚动设置列与底部固定操作。

- 输出色彩空间下拉固定提供四项：`sRGB`、`Display P3`、`Adobe RGB (1998)`、`ProPhoto RGB`。导出文件转换到所选空间并嵌入对应 ICC；当前 SDR 工作空间不会因此扩展为 HDR 或宽色域工作空间。
- HEIF 仅在真实设备编码能力探测通过后可选；编码语义固定为 SDR、sRGB、8 bit。探测失败时 HEIF 禁用并保留明确原因；已保存但当前不可用的 HEIF 配方必须拒绝执行，不得静默回退或伪装为 JPEG。
- JPEG 与 HEIF 显示质量百分比标签；TIFF 保留可选的 16-bit RGB 与无损 Deflate 开关。格式切换只显示对应控制，原有分辨率、默认外观、元数据和配方链路继续有效。
- 设置内容继续位于可滚动列，安全区、固定导出操作和处理时禁用状态保持；大字体、横屏与平板维持现有约束宽度和可读性。

证据：依据 `review-packet.json` 与 `finish-review.md` 审阅四种配置共 28 张原始截图，并对照当前 `ExportScreen.kt`、`DESIGN.md`、`.impeccable/design.json` 及本文件历史记录。R08 评审结论为 ship；未发现需要修复的材料性 UI 问题。PRODUCT.md 缺失，未据此补造产品语境。现存历史报告与设计 token 保持不变；本次仅记录行为合同，不修复预先存在的偏差。

## R10-A 持久导出任务浏览器行为合同

日期：2026-11-19。普通延伸 incumbent Theia Operate 风格；沿用现有 DESIGN.md 与 `.impeccable/design.json` 的视觉权威，不建立新视觉世界。此条仅约束持久导出任务浏览器。

- 任务列在宽屏居中并限制为600dp，手机上占满可用宽度并保留水平留白；内容为原生平面滚动列表，遵循系统安全区。顶部提供返回与刷新，返回键和顶部返回均关闭任务页，刷新在处理中禁用。
- 每项呈现源文件名、明确状态、冻结选项摘要、更新时间、尝试次数及可用错误/恢复说明。状态与错误采用现有主题语义色；延续炭灰表面、纸白正文与琥珀强调，不引入独立配色或装饰卡片。
- 失败或取消的有效任务只允许按原冻结请求重试，不采用当前编辑参数或重新生成随机种子；成功任务不提供重试。已提交文件视为成功并去重，避免再次发布。
- 原图丢失或授权失效时可重新选择来源；仅当文件内容 SHA-256 与任务原图完全相同时更新引用。错图、取消选择或校验失败不得改动任务，并应给出明确错误与恢复路径。
- 移除前显示确认；确认只删除任务元数据，不删除原图或已发布输出。处理中任务不可移除。
- 来源与应用身份不匹配时拒绝执行并说明原因，不能发布输出；重复/已提交结果不得再次发布。无法读取的记录保留为不可操作条目，并保留可理解的错误提示。

证据与范围：finish-review.md 对要求的20张原始截图完成审阅，覆盖 phone、large-font、landscape、tablet 各5张，以及失败、成功、来源变化、应用变化和返回首页状态；结论为 SHIP，未发现材料性 UI 或合同缺陷。该结论仅针对 R10-A 任务浏览器表面；R10 的 DI 宿主、table/encoder 宿主迁移仍未完成，不由本次评审声明完成。PRODUCT.md 缺失；本文不据此补造产品语境，也不改写历史文字、设计 token 或 sidecar。
