# R06 成片裁切、胶片旁路和透视

日期：2026-11-18。基线 `cdae7ce`。对应 [2.4.2 开发清单 R06](../upstream-2.4.2-android-roadmap.md)。参考桌面 `Sources/Model/Geometry.swift` 与 `EngineWire.swift`，保留 Android 原有引擎与调色精度合同。

## 行为与阶段

透视（水平/垂直 ±30°）在解码、RAW 白平衡与镜头校正后处理源像素，再交给原有源裁剪/拉直/90°旋转/翻转及胶片流程。采用中心固定的 K·Rx·Ry·K^-1 映射及 48 次二分求无黑边范围；每个样本按像素中心双线性读取，不用缩图替代原尺寸。源裁剪工作区展示同一透视后的构图。

成片裁切位于胶片/相纸、片边/日期及完整画面调色之后，最终尺寸限制之前。自由拖动、比例、取消、重置、完成沿用原有裁剪工作区；独立持久化的矩形不覆盖源裁剪。暗角始终使用完整成片坐标，预览直方图统计裁后的画面。JPEG/PNG/16-bit TIFF、单张/批量/虚拟副本、灯台输出、高清预览及软打样接通。DI TIFF 属于未调色的胶片密度输出，不应用成片裁切，胶片关闭时不提供 DI。

胶片旁路保留解码、RAW 白平衡、镜头校正、源几何和成片调色；不运行胶片/相纸模拟，也不生成片边和日期。材料及效果参数仍保存，重新开启时恢复。拍摄面板保留 RAW 控件，暂收起无效胶片控制；打印面板显示明确状态。原图对比仍指向原始源图。

裁切工作区按可用宽高响应：短宽横屏保留顶部工具栏，将比例、重置和拖动说明放入可纵向滚动的侧栏，宽度为可用宽度的 28% 并限制在 200–280dp，使照片占据其余宽度及完整可用高度；竖屏和较高平板继续使用照片在上、控件在下的既有纵向布局。四配置实拍覆盖手机、增大字体、短横屏和平板，包含源裁切与成片裁切操作及状态截图。

## 兼容与实现

新参数缺省为中性/关闭；默认 sidecar 不增加新字段。预设/分组同步归属明确：胶片旁路在 FILM，透视及成片裁切在 GEOMETRY；默认复制不带几何。批量写入删除旧的可选字段，避免清除后残留。历史、重启和虚拟副本保存两级裁切。

普通胶片、零透视仍使用旧 JNI；新宿主映射位于 Android 自有 `scene_session.cpp`，没有修改兄弟项目引擎。胶片旁路采用有独立所有权的 CPU float32 源和 native U16 结果；原生结果不交给引擎 GPU 的 free。透视改变/旁路开关从原始预览像素重新绑定；逐行取消、绑定取消、结果越界和关闭处理可测试。宿主渲染身份增加 `scene-geometry=1`。

成片预览直接按有界行写入裁后 Bitmap 并同步统计直方图，不创建完整调色 Bitmap 加裁后副本，也不读取全图 ARGB 数组。sRGB/P3 与先完整调色再裁的显示参考逐像素一致。

成片导出裁切读取完整宽度的有界行，先按原坐标调色，量化 U16 再取矩形，随后按既有面积缩放限制尺寸。neutral grade 的裁切逐位保留 U16；未裁切保留旧导出顺序。有限裁切的非中性调色多一次 U16 中间量化，独立像素测试与最终格式读回验证；没有降到 8-bit 中间图。它不解决首次全尺寸源/显影的内存峰值。

## 耗时与范围

仅 API37/x86_64 模拟器。原尺寸数字旁路 24.5MP NEF 的一次独立分段测量：解码约 1.3s，native 绑定约 0.12s，CPU 几何与 U16 编码约 5.1–6.3s；读行计算完整摘要约 0.13–0.17s。过程 PSS 约 698,000KiB（约682MiB），不能称为内存优化。实际带双轴透视/裁切的原尺寸 PNG 一次约 15–18s、随后缓存路径约 5.8s；缓存状态、编码和系统负载不同，不能把顺序样本当作严谨性能对比或手机耗时。最终原始记录随聚合证据保存。

未拿到小米15 Ultra 失败 DNG，未补测小米/vivo ARM/Adreno 驱动，不承诺这些真机问题已解决。普通非DNG TIFF 回导、专业色彩空间扩展与细节瓦片仍属后续工作。新 UI 文案集中在 `values/scene_geometry.xml`，不宣称四语言已完成。
