# R10 灯台拼版与编码

2026-11-20。灯台在独立渲染进程内解码已准备的输入、绘制项目画布并编码 PNG 或 JPEG。传入的是冻结布局和只读文件描述符，临时标识用来关联同一张照片的多次摆放。编辑器在发布前复核来源内容及编辑版本，只有已完整编码的文件才进入相册发布流程。

API 37 x86_64 模拟器的全部五组回归通过。两份完整文件与本地参考逐字节一致，覆盖 1600×1600 透明灯台 PNG 和 1697×2400 A4 JPEG，两次测试合计 757 毫秒，包含生成参考并核对。测试还覆盖图层旋转和重叠、光源关闭、标题、日期和编号，以及发布写入失败和提交前来源变更时删除相册临时记录。

真实 Z6II NEF 虚拟副本生成的 1600×1101 PNG 与独立参考最大通道差为 0。该次模拟器缓存命中从提交到返回耗时 2.193 秒。实际界面验证透明 PNG、A4 JPEG、过期编辑拒绝、应用最新编辑、取消和返回后继续编辑与撤销。混合原图和编辑外观、未编辑透明 PNG、重复摆放及容量保护也通过。
