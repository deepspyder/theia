任务恢复页沿用暗房Operate界面，从首页更多操作或导出页进入。每个记录包含冻结请求、原图SHA-256与可恢复URI、原随机种子、容器/尺寸/色域/压缩/命名规则、提交时刻/命名日期、完整APK资源身份、状态、执行次数和发布凭据。只存私有任务元数据，不把源图像素写入日志。最近32条已结束任务滚动保留；移除记录不会删除原图或已导出文件。

重新导出是用户明确触发的完整任务重做，不猜测恢复到GPU中途。先原子抢占失败/取消记录，同一进程不同Store实例只能有一个请求成功；再通过同一源快照和独立宿主校验源SHA、解码器、引擎、整个APK内容和冻结选项。任意身份变化拒绝执行，提示打开原图重新导出。随机实现和原日期/名称后缀保留；不套用当前编辑页参数。已提交文件优先认定成功，不重复发布。遗留未提交目标须先清理，防止残留项堆积。

丢源/撤权可使用系统文档选择器重新选择原图；仅文件字节指纹完全相同时更新任务引用，取消/错图不改记录，读入过程中可取消。继续使用现有持久读取授权；provider不能长期授权时不能保证不重新选图，任务页明确提供恢复入口，不私自大量归档原片。

请求schema5读取schema1—4，新增原命名时间/日期和APK身份；旧任务缺源地址时仍保留并提示从原图重新导出。journal version2读取旧记录并保留未知字段；超过256KiB、损坏、未来版本、缺关键种子的记录只读保留。AtomicFile旧bak恢复，启动恢复只在进程级导出门锁内执行，避免另一个ViewModel恢复掉正在执行的任务。只读细节/打样继续不创建任务凭据。
