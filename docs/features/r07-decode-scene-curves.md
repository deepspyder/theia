# R07 Decode 场景曲线

日期：2026-11-19。基线 `6a7f8b5`。对应[开发清单 R07](../upstream-2.4.2-android-roadmap.md)。Mode: Operate；沿用暗房与既有五通道成片曲线编辑器，增加独立 Decode 目标，不引入新视觉系统。

## 阶段与数学合同

场景曲线在源图解码、白平衡、几何、自动测光归一及已有 Scene Latitude 之后，光谱上采样与胶片曝光之前。五行依次存 RGB、亮度、R、G、B；执行时先亮度标量增益，再 RGB 各通道增益，最后单独通道增益。亮度使用输入空间 RGB→XYZ 的 Y 行，中灰为0.184。坐标0…1映射到−8…+8EV；以 E=log2(v/0.184)+c 取样，c为胶片曝光补偿。当前节点乘2^(f(E)−E)，后续原有胶片曝光仍乘2^c，因此曝光补偿沿曲线移动场景，不能改成在成片RGB上调曲线。超出±8EV时保持端点自身增益；非正或非有限值不读取自身行的对数。

自动测光和胶片/相纸宽容窗口测量排除用户曲线，片边、齿孔、文字及日期在后续节点生成。关闭胶片模拟时曲线保存但不应用，入口明确禁用；重新开启后恢复。该行为与参考项目的胶片曝光轴一致。既有0…1编码空间成片曲线保持独立，两个模型不会互相覆盖。

参考为本地桌面 `Model/FilmParams.swift`、`Model/CurveMath.swift`、`engine/src/pipeline/scene_latitude.cpp`及`scene_latitude.metal`。Android只修改自有适配层：在生成引擎副本中加入schema、参数校验、SHOOT失效、节点、进度与Vulkan绑定，未写入兄弟桌面checkout。新增原始、bounded和windowed-v3着色器遵守现有72字节标量origin ABI：仅像素输入binding0和输出binding4移动，参数/表/计数固定。

## 存储、交互与恢复

`scene_curves`为独立可选sidecar对象（version1、stops8、五通道控制点）；旧记录缺省恒等，不增加默认JSON字段。五行各129点、五位小数的`scene_curve`字符串传入引擎；恒等及冗余对角控制点均发送空串，不分配/执行场景节点。清除曲线显式发送空串，避免复用旧负片。宿主渲染身份增加`scene-curve=1`，缓存冻结快照包含独立曲线。

曲线入口位于拍摄的全部调整，在胶片模拟开关后。沿用照片预览、五通道、控制点、精细输入/输出、取消手势、复位及撤销重做；显示EV读数与轴说明，不把成片直方图误画在场景EV坐标上。手机/大字/横屏/平板使用现有布局。EV文案增加后，Decode图高局部缩减48dp，为帮助文字和底部操作保留空间；成片曲线图高不变。

手势预览重新显影但不落盘，结束时提交一次；取消、切图、复制、导出及版本边界恢复未提交草稿。预设和同步的DECODE组包含场景曲线，JPEG/WebP也可应用；只有相机WB仍按RAW跳过，组名明确为“解码白平衡与场景曲线”。旧模板无该字段时按恒等复位。未知版本、错误轴或类型原样保留；预览可查看源画面并显示明确警告，正式输出拒绝默默忽略。用户可显式复位，或关闭胶片模拟保留未知曲线数据。

## 已执行验证

- 打包Vulkan独立NDK程序对照CPU档位参考，8组320,024像素覆盖黑位/负值/宽动态范围、不同曝光补偿、亮度/RGB/单通道/组合及平坦曲线；普通与262,144字节描述符窗口路径逐位相同，跨窗口与部分末工作组实际执行。最大相对误差约1.54×10⁻⁶；大线性数值的绝对误差与逐组记录保存在证据中，不把它当作编码图像码值误差。测试程序不链接到APK，无新增JNI测试入口。
- 真实胶片结果与独立计算曲线后的线性源参考比较，sRGB/ProPhoto、三档曝光及自动测光完整顺序的62,489个像素最大差1个U16码值；SHOOT失效/打印reprint、清除后恢复、非法wire拒绝、测光和medium窗口不变通过。自动测光参考先独立乘测量增益，再计算场景曲线，最后由关闭测光/曲线的胶片路径生成参考。
- 默认8组完整U16输出与原基线逐位相同，包含旋转、翻转、拉直、片边和日期。模型版本/轴/语言区域、未来数据保留/正式输出防护、Decode与成片分组及JPEG/RAW复制隔离通过。
- PNG/WebP/JPEG EXIF6共18次实际原尺寸/自定义PNG、16-bit TIFF、JPEG输出；PNG全图、TIFF逐行全部U16样本与参考一致，JPEG核对完整解码和平均误差。草稿取消/提交、两个曲线的撤销隔离、重新打开和独立进程redo恢复通过。
- 6064×4040 NEF实际三格式原尺寸输出、重复完整PNG摘要、RAW WB重解码保留曲线及自定义短边通过；批量虚拟副本和两套1600px灯台输出携带各自曲线，与完整画面参考对照通过。

## 耗时与限制

仅API37/x86_64模拟器。首轮按PNG→TIFF→JPEG顺序的24.5MP NEF带曲线输出约18.039s、1.305s、1.517s，重复PNG约3.497s；后续容器复用已显影缓存，不能将这些顺序样本解释为编码器快慢或真机速度。RAW WB变化后自定义短边PNG约15.743s，包含重新显影；各阶段/缓存与完整记录另存。没有缩小原尺寸输出，也没有将16-bit TIFF降到8-bit。

小米/vivo ARM/Adreno真机未连接，用户小米15Ultra失败DNG仍缺少，不声称相关驱动/RAW问题已解决。本批未改变专业输出空间、HDR或全尺寸显影峰值，相关范围仍在R08/R09/R10。新文案资源化不代表四语言完成。
