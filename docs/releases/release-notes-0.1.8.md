# Theia v0.1.8 · 暗房与导出更新

发布日期为 2026 年 11 月 20 日。以下是从 v0.1.7 升级后可以用到的新功能，以及已有功能本次的改进。

## 新增功能

- **自定义导出尺寸与文件名。** 可按长边、短边或总像素数限制最终成片尺寸，保留宽高比。原图小于目标尺寸时保持原尺寸。文件名可组合原图名、胶片、相纸和导出日期，重名时自动加序号。已有导出配方新增重命名和删除。
- **更多文件色域和格式。** JPEG 和 PNG 新增 Display P3、Adobe RGB (1998) 和 ProPhoto RGB。原有 sRGB 和 Display P3 TIFF16 增加 Adobe RGB (1998)、ProPhoto RGB 与可选的 Deflate 无损压缩。设备支持时，可导出 sRGB HEIF。
- **导出任务可以重试。** 在「导出任务」中查看失败或取消的记录，按当时的编辑和设置从头重新导出。原图权限失效时可重新选择同一文件。保存前复核原图，已发布的成片不会重复保存。
- **撤销和重做跨会话保留。** 重新打开照片后，可以接着使用该照片的撤销和重做记录。新增 RAW 灰点吸管和成片灰点吸管，分别在解码和成片阶段校正白平衡。
- **新增胶片前曲线、透视与成片裁切。** Decode 场景曲线作用于胶片模拟前，原有成片曲线继续独立使用。可校正水平和垂直透视，也可在显影、调色和片边完成后再裁切。关闭胶片模拟可直接进行数字调色，重新开启后恢复此前的胶片设置。
- **按原尺寸检查细节。** 导出页新增 100% 查看，可从真实成片检查对焦、颗粒和片边。色彩打样可查看所选文件色域的效果。
- **新增应用设置。** 可调编辑预览质量，设定新照片的默认胶片和相纸，调整或清理成片缓存，也可导出诊断报告。

## 修复与改进

- **扩展独立导出的范围。** v0.1.7 已把单张和批量的渲染放入独立进程。本版把成片调色与文件编码、实际照片的 DI 渲染，以及观景台拼版与 PNG／JPEG 编码也交给独立进程。提交到相册前会复核来源，取消或写入失败会清理未完成的输出。
- **改善 RAW 导入与大图导出。** 修复部分系统文件提供方交付的 RAW 无法打开的问题，补齐分段文件的读取。改进部分 Vulkan 设备的大图渲染兼容性和带片边原尺寸导出的检查。
- **保留观景台外观。** 同一项目可混用原图外观和已编辑外观。已有的透明 PNG 和 A4 JPEG 沿用原尺寸和版式。项目中的照片编辑过期时，可选择应用最新编辑再导出。

## 安装与验证

通用安装包为 `Theia-v0.1.8-universal.apk`，版本代码为 `9`，支持 `arm64-v8a` 和 `x86_64`。沿用原应用标识和更新证书，APK 通过 v1/v2/v3 签名及 16 KiB 对齐检查。

API 37 x86_64 模拟器验证了 48 个常规导出组合、6064×4040 NEF、HEIF、TIFF 重试，以及观景台的透明 PNG、A4 JPEG 和取消清理。小米、vivo 等 ARM 真机的兼容性仍需单独验证。
