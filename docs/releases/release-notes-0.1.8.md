# Theia v0.1.8

2026 年 11 月 20 日发布。

## 编辑与查看

- 撤销和重做记录跨会话保存。新增灰点白平衡吸管、成片裁切、透视调整、数字旁路和 Decode 场景曲线。
- 原尺寸细节支持按需加载瓦片和 100% 查看，色彩打样可预览所选导出色域。
- 设置增加预览质量、默认胶片和相纸、缓存预算与诊断导出。

## 导出

- 支持按长边、短边或像素总量设置尺寸，并保存或管理导出配方。文件名支持原图名称、材料和日期组合，自动处理重名。
- 支持 sRGB、Display P3、Adobe RGB (1998) 和 ProPhoto RGB 输出，以及 TIFF16 无损 Deflate。受支持的设备可导出 sRGB HEIF。
- 导出任务页支持按冻结的参数安全重试。程序在保存前复核来源，避免重复发布文件。单张、批量、DI 渲染、成片编码以及灯台拼版使用独立进程处理相应步骤。
- 灯台保留原图和编辑后的外观，可导出透明 PNG、A4 JPEG。改进部分 RAW 内容提供方的读取方式和全尺寸渲染保护。

## 安装与验证

通用签名安装包 `Theia-v0.1.8-universal.apk` 支持 arm64-v8a 与 x86_64，版本代码为 9，沿用现有应用标识和更新证书。

验证覆盖 API 37 x86_64 模拟器上的真实 NEF 全尺寸输出、HEIF、TIFF 重试和灯台 PNG／JPEG。小米、vivo 等 ARM 真机兼容性仍需实机验证。
